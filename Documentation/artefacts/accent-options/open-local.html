Accent options for harukamirai.engineer

Six accent pairs for the grimoire, plus the pair now in the file, each measured against the WCAG floor and photographed on the real site in both leaves. Choose by looking.

1. How to choose

The verdict this answers. The current accent was called too plainish and boorish. A deep navy is the safest accent there is, which is exactly why it reads flat. Everything below has more character than that and still clears the same legibility floor.

Only three tokens move. The grounds, the text inks and the whole grimoire material set are fixed, so a candidate is a small, total swap:

  [data-theme="leaf-4"]  the page          [data-theme="leaf-5"]  the ink
  ---------------------------------        ---------------------------------
  --bg            #e1e6ea    FIXED         --bg            #0b1220    FIXED
  --bg-elevated   #f0f3f6    FIXED         --bg-elevated   #131c2c    FIXED
  --text          #131a20    FIXED         --text          #e9eef4    FIXED
  --accent        ........   MOVES         --accent        ........   MOVES
  --accent-hover  ........   MOVES         --accent-hover  ........   MOVES
  --gold          ........   MAY MOVE      --gold          ........   MAY MOVE
        |                                        |
        +--- derived, not chosen ----------------+
             --accent-glow   = accent at 20% / 30% alpha
             --clover-fifth  = accent   (leaf-5 only: fifth leaf, demon eye)

  :root  --leather-*  --foil  --parchment*  --gilt*  --page-ink*   NEVER MOVE
         the book is one physical object in both themes
Two looks deliberately avoided. A single muted accent on a warm cream ground, and a single bright acid accent on a near-black ground. Neither ground exists here any more - leaf-4 is cool linen-grey and leaf-5 is chromatic woad indigo - and every dark-leaf accent below is held off the top of its gamut so it reads as pigment rather than as an alert.

Three things are worth doing in order: read the strip in section 2 to find the two or three that feel right, put those against each other on one page in section 3, then open the candidate's own section for its six full renders.

12. If you pick one

Replacing the values in the two [data-theme] blocks of src/app/globals.css is the whole change. Nothing else in the file reads a literal accent colour, and no component does either - --accent is referenced through var() throughout.

Changes by hand

  • --accentlinks, kickers, filled buttons, selection
  • --accent-hoverevery hover state on the above
  • --goldonly where the candidate says it moves

Changes with it

  • --accent-glowthe accent at 20% (leaf-4) / 30% (leaf-5) alpha
  • --gold-glowthe gold at 16% / 25% alpha
  • --clover-fifthleaf-5 only: the fifth leaf and the demon eye are literally the accent

Does not move

  • --bgboth grounds are fixed, with --bg-elevated and --bg-inset
  • --textthe inks are fixed, with --text-muted and --text-subtle
  • --leather-*and --foil, --parchment*, --gilt*, --page-ink*: the book is one physical object in both themes
The comment block goes stale. The palette doctrine at the top of globals.css names the current colours and quotes their measured ratios, and it lists alternates B and C. Whichever candidate wins, that prose has to be rewritten in the same commit or the file starts lying about itself.

13. Method

Nothing on this page is estimated. The contrast figures come from a checker; the renders come from real production builds of an isolated copy of the site.

WCAG 2.x relative luminance over sRGB, implemented in palette.py beside this file. The implementation was validated first by reproducing thirteen ratios already recorded in globals.css - text, muted, subtle, accent, gold, foil on leather, page-ink on parchment and gilt-ink on parchment - all of which matched to two decimals before any candidate was measured.

C_lin = C/255 <= 0.03928 ? (C/255)/12.92 : (((C/255)+0.055)/1.055)^2.4
L     = 0.2126*R_lin + 0.7152*G_lin + 0.0722*B_lin
ratio = (L_max + 0.05) / (L_min + 0.05)

The same file is the single source for this page, so no figure here is typed by hand. Regenerate with python3 build-index.py.

  1. The repository was copied to a scratch directory, excluding node_modules, .next and .git. The working repository was never modified; its globals.css checksum was recorded before and after the run and did not change.
  2. For each candidate, only the accent tokens inside the two [data-theme] blocks of the copy were rewritten, then next build ran from clean and next start served it.
  3. Before any screenshot, every <link rel=stylesheet> was fetched and asserted to return 200, and the served CSS was searched for that candidate's own hex values. A 404, or the wrong variant being served, aborts the run rather than producing a plausible-looking wrong picture.
  4. The full-screen story overlay was dismissed by clicking the button matching /browse portfolio directly/i, the theme was set through the site's own hm-theme storage key, and the page was scrolled to the bottom and back so the IntersectionObserver reveals had fired.
  5. Captured at a 1440 × 900 viewport, clipped to 1440 × 1700 beyond the viewport and written at 0.75 scale.
What the renders were built from. The snapshot was taken from the working tree at b87a565 plus the uncommitted edits present at that moment. While the renders were being produced, separate work landed in the same working tree touching src/app/work/page.tsx and src/components/HeroIntro.tsx, so the Work page and the hero have moved on in layout since these pictures were taken. The two [data-theme] token blocks are byte-identical between the snapshot and the live file, so every colour and every ratio on this page describes the current globals.css exactly. Judge the colour, not the furniture.
One thing is hidden in the renders. The two scroll-rune seals are position:fixed, so in a capture taller than the viewport they photograph stranded in the middle of the page. They are hidden immediately before each shot so the same pixels compare across candidates. Nothing else was changed.
What this page does not tell you. Contrast is measured, and the renders are real. Everything about character - whether a colour reads as pigment or as a warning, whether purple and gold reads as a codex or as a luxury template - is judgement, and it is yours. The names and the one-line rationales are colour argument, not history.
