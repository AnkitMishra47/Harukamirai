# 遥か未来 — Harukamirai.engineer

**Ankit Mishra | Senior Software Engineer**

The "Grimoire No. 17" portfolio. A high-concept, magical-tech showcase built with Next.js 15, Framer Motion, and Tailwind CSS.

## 🔮 Core Concept
*Haruka Mirai* (Distant Future). The site is themed around the concept of a magical grimoire—featuring interactive "summoning" animations, a 3D interactive resume, and a reality-warping theme toggle (4-leaf/5-leaf clover).

## 🚀 Quick Start (Local Dev)

1. **Clone the repo:**
   ```bash
   git clone https://github.com/AnkitMishra47/Harukamirai.git
   cd Harukamirai
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

## 🛠 Tech Stack
- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS 4.0
- **Animations:** Framer Motion (Motion 12)
- **Typography:** Fraunces (Display), Geist (Sans), Shippori Mincho (JP)
- **Deployment:** Vercel

## ✨ Key Features
- **3D Grimoire Resume:** An interactive book chronology of career milestones.
- **Persistent Magic Circle:** A GPU-accelerated background effect that stays active across routes.
- **Summoning Reveal:** Elements enter the viewport with magical circle animations.
- **Anti-Magic Theme:** A global theme shift with reality-distortion filters.
