## 3. Measured results

Lighthouse 12, headless Chrome, mobile profile, `next start`, home route.
Scores swing up to 6 points between identical runs on this box.

| | Live before | Foundation | Grimoire | Fable |
|---|---|---|---|---|
| Score | 54 | 93-96 | 90-96 | 99 |
| Largest Contentful Paint | 23.7 s | 2.9 s | 2.4-3.1 s | 2.3 s |
| Speed Index | 11.9 s | 1.5 s | 1.5-3.3 s | 0.9 s |
| Page weight | 4,425 KiB | 338 KiB | 342 KiB | 242 KiB |
| First-load JS | 167 kB | 167 kB | 118 kB | 114 kB |

The old site preloaded 125 font files totalling 4.26 MB because the Japanese
font had no subset. That was most of the slowness on its own.

Per-direction detail lives in
`docs/superpowers/plans/2026-09-19-foundation-lighthouse.md`,
`docs/superpowers/plans/2026-09-19-grimoire-fast-lighthouse.md` (Grimoire
worktree) and `docs/superpowers/plans/2026-09-19-fable-lighthouse.md` (Fable
worktree).

**Known gap.** The spec target of LCP under 1.5 s is not met by either
direction. Observed unthrottled LCP equals first paint (169 ms), so the page
does paint immediately; the simulated 2.3-2.9 s is Lighthouse's slow-4G model
counting the Next.js runtime and the display font as LCP dependencies. Closing
it further means dropping the web font or leaving Next.js. Neither is in
scope, and this was reported rather than hidden.
